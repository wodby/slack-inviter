# Wodby Slack community landing page

The lightweight landing page served at `https://slack.wodby.com/`. It deploys
as the `nginx` service in Wodby's HTML application stack and redirects new
members to a native Slack shared invitation link without storing email
addresses or using Slack API credentials.

## Runtime configuration

Both variables are required. The container refuses to start when either value
is missing or malformed.

| Variable | Description |
| --- | --- |
| `SLACK_INVITE_URL` | A `https://join.slack.com/.../shared_invite/...` URL generated by Slack. |
| `SLACK_INVITE_EXPIRES_AT` | The invitation expiry as a UTC ISO 8601 timestamp, for example `2026-09-11T23:59:59Z`. |

The page disables its join button after the configured expiry. The `/join`
redirect keeps the actual invitation destination in runtime configuration, so
rotating a link does not require a source change.

## Local development

For a quick visual preview:

```sh
python3 -m http.server 8080 --directory public
```

The checked-in `public/config.js` keeps the button active for local previews.
The `/join` redirect is provided by the container and will not work in this
static-only preview.

To exercise the complete HTML-stack image locally:

```sh
docker build \
  --build-arg WODBY_BASE_IMAGE=wodby/nginx:1.31-5.48.5 \
  -t wodby/slack:local .
docker run --rm --env-file .env -p 8080:80 wodby/slack:local
```

Copy `.env.example` to `.env` and replace both example values first.

Run the dependency-free checks with:

```sh
npm run check
```

## Wodby deployment

1. Create a Wodby application from the managed HTML stack.
2. Connect this repository as the `nginx` service build source and select Wodby
   CI.
3. Add the two runtime variables above to the `nginx` app service.
4. Run the native pipeline in `.wodby/pipeline.yml`. It checks the page, builds
   against the HTML stack's injected Nginx base image, releases it, and deploys
   it through the Wodby CLI.
5. Verify the technical route and `/.healthz`, then attach
   `slack.wodby.com`.

The page and `config.js` are deliberately uncached. Static assets use short,
bounded cache lifetimes so updates do not require fingerprinted filenames.

## Invitation renewal

Slack shared invitation links expire after at most 30 days or 400 uses. Before
the current link expires:

1. Generate a new shared invitation link in Slack.
2. Update `SLACK_INVITE_URL` and `SLACK_INVITE_EXPIRES_AT` together in Wodby.
3. Redeploy or restart the service so the runtime template is regenerated.
4. Open `https://slack.wodby.com/`, follow the join button, and complete one
   invitation test.

Set an operational reminder at least seven days before every expiry.
