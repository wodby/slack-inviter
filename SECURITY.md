# Security policy

Please report vulnerabilities privately through GitHub's security advisory
feature for this repository. Do not include Slack tokens, Turnstile secrets,
email addresses, or other production data in a public issue.

This project depends on an undocumented legacy Slack endpoint. Endpoint
removal or token revocation is an operational compatibility issue rather than
a vulnerability, but reports of credential exposure or a bypass of Turnstile
or request limiting should be treated as security-sensitive.
